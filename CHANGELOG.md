# Changelog

## 0.3.0 · development

- Initial KiCad 10 PCB Editor action plugin, portable runtime discovery and installer.
- Source and local PCM ZIP builders; dependencies installed for each KiCad Python.
- Board export and linked single-sheet schematic / board / library export.
- Complex PTH copper represented by a round drilled pad and two native copper lands.
- One-to-one Eagle net naming, including whitespace and case collisions.
- Informational notes for distinct source nets differing only by whitespace.
- No user PCB designs or platform-specific wheels included in the repository.
- Cross-platform source CI defined; native Linux/macOS and Fusion editing validation pending.
